    Section 2 08/26: Introduction and Review

    Today, we introduce the course, various policies, and then review some prerequisite mathematical material. The course information won’t be repeated here - all of the information can be found on Brightspace, via the course syllabus and other materials.
    🔗

    Subsection 2.1

    🔗
    \bigskip

    Definition 2.1.

    The left limit
    \begin{equation*} \lim_{x \to c^-}f(x) \end{equation*}
    is defined as the value that \(f(x)\) approaches as \(x\) approaches \(c\) from below, if it exists.
    🔗
    Similarly, the right limit,
    \begin{equation*} \lim_{x \to c^+}f(x), \end{equation*}
    is the value \(f(x)\) approaches as \(x\) approaches \(c\) from above, if it exists.
    🔗
    If the left and right limits are equal, then the limit
    \begin{equation*} \lim_{x \to c}f(x) \end{equation*}
    exists and is their value.
    🔗
    🔗

    Question 2.4.

    When does a limit not exist?
    🔗
    Answer.
    When there is a jump in the graph of \(f(x)\) at the point at which we want to evaluate the limit.
    🔗
    🔗
    🔗

    Remark 2.5.

    The value of \(\lim_{x \to c}f(x)\) depends on the values of \(f(x)\) close to \(c\text{,}\) but does not depend on \(f(c)\text{.}\) In fact, we don’t require \(f\) to be defined at \(c\) at all. Or, we can have a discontinuity at \(c\) where
    \begin{equation*} f(c) \neq \lim_{x \to c}f(x). \end{equation*}
    If this is the case, we say \(f\) is not continuous at \(c\text{.}\)
    🔗
    🔗

    Problem 2.10.

    Some practice problems for the students:
    🔗
    1. Let \(f(x) = \dfrac{x}{(x + 1)}\text{.}\) Evaluate
      \begin{equation*} \lim_{x \to -1}f(x) \end{equation*}
      numerically, or state that it does not exist.
      Answer.
      For \(x < -1\text{,}\) \(f(x) > 0\text{,}\) and for \(x > -1\text{,}\) \(f(x) < 0\text{,}\) so the only way the limit can exist is if it equals \(0\text{.}\) Evaluating numerically, we see that \(f(x)\) increases as \(x \to 0^{-}\) and decreases as \(x \to 0^{+}\text{,}\) so the limit does not exist.
      🔗
      🔗
      🔗

    4. Let \(f(x) = \dfrac{x}{(x + 1)^2}\text{.}\) Evaluate
      \begin{equation*} \lim_{x \to -1}f(x) \end{equation*}
      numerically, or state that it does not exist.
      Answer.
      This time, \(f(x)\) is always negative. The limit will be \(-\infty\text{.}\)
