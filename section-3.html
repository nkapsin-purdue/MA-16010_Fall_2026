    Section 3 08/28: Finding Limits Analytically

    Last class, we defined limits and used numerical and graphical techniques to find them. Both of these techniques can be slow, so today we will introduce faster ways to determine limits for certain nice functions.
    🔗

    Question 3.1. Warm-up Question.

    What is a limit? What does the statement \(\lim_{x\to -2} x^3\) mean? Try to come up with a 1-2 sentence description. Use casual language if it helps you understand the concept.
    🔗
    🔗

    Subsection 3.1 Continuous Functions

    Last time, we saw that for some functions, finding a limit is as simple as plugging in the number we’re approaching into the function. We introduce some terminology we can use for such functions:
    🔗

    Definition 3.2.

    We say that a function \(f(x)\) is continuous at (the point) \(c\) if the following is true:
    \begin{equation*} \lim_{x\to c}f(x) = f(c) \end{equation*}
    In other words, when the limit of a function at a point is equal to the function at that point.
    🔗
    We say that a function is continuous if it is continuous at \(c\) for every single choice of \(c\text{.}\)
    🔗
    🔗
    If we are every asked to compute the limit of a continuous function at a point, we can just evaluate the function at that point. Graphically, continuous functions are those that you can draw on a piece of paper in one stroke without lifting up your pen.
    🔗
    Some useful examples of common continuous functions that we will see:
    • All polynomials
      🔗
      🔗
    • Sine and Cosine
      🔗
      🔗
    • \(\displaystyle e^x\)
      🔗
      🔗
    • \(\ln(x)\hspace{5mm}\) (For positive values of \(x\))
      🔗
      🔗
    🔗

    Example 3.3.

    Solve
    \begin{equation*} \lim_{x \to 3}(x^{2} + 1) \end{equation*}
    🔗
    Answer.
    \(x^{2} + 1\) is a polynomial, so it’s continuous. In particular, it is continuous at \(x = 3\text{.}\) Thus if \(f(x) = x^{2} + 1\text{,}\) then
    \begin{equation*} \lim_{x \to c}f(x) = f(c) \end{equation*}
    for any \(c\text{,}\) so in this case we have \(\lim_{x \to 3}(x^{2} + 1) = 3^{2} + 1 = 10\text{.}\)
    🔗
    🔗
    🔗
    🔗
    This example was an example of finding a limit analytically. We will say that we are finding a limit analytically when we are using any special technique or rule that allows us to solve a limit more concisely than writing a big numerical table or squinting at a graph.
    🔗
    🔗

    Subsection 3.2 Discontinuous Functions

    We introduce several more of these rules below when finding \(\lim_{x\to c}f(x)\text{:}\)
    1. \(f(c)\) evaluates to \(\dfrac{\langle\textit{nonzero number}\rangle}{0}\text{.}\) This means that \(f(x)\) is not defined at \(c\text{,}\) and that there is a vertical asymptote at \(c\) instead. We will analyze the limits at \(c\) from below (left) and above (right) to get more information, as illustrated by the following example.

      Example 3.4.

      Evaluate
      \begin{equation*} \lim_{x \to 5}\frac{1}{x - 5}. \end{equation*}
      🔗
      Answer.
      Trying to evaluate \(f(5)\) would give us \(\dfrac{1}{0}\text{,}\) so we need to check the sign of \(f(x)\) above and below \(5\) (and close to it). Graphing \(x - 5\text{,}\) we see that it is negative to the left of \(x = 5\) and positive to the right, so \(f(x)\) will be negative to the left and positive to the right. Thus \(\lim_{x \to 5^-}f(x) = -\infty\) and \(\lim_{x \to 5^+}f(x) = \infty\text{,}\) so the desired limit does not exist.
      🔗
      🔗
      🔗

      Remark 3.5.

      When a function shoots up vertically to infinity on both sides, or shoots down vertically to negative infinity on both sides, we allow ourselves to write \(\lim_{x\to c}f(x) = \infty\) or \(\lim_{x\to c}f(x) = -\infty\text{,}\) respectively. This is a little handwavey, since "\(\infty\)" is not a number that we can work with - what is important is that the limit describes the behavior of the function right around \(c.\)
      🔗
      🔗
      🔗
      🔗
    2. \(f(c)\) evaluates to \(\dfrac{0}{0}\text{.}\) In this case there might be a vertical asymptote at \(c\text{,}\) but we can’t be sure quite yet. To handle functions that give us this, we will try to reduce them into a simpler form that can be handled by another case.
      🔗
      In this course, we will only do this by factoring and cancelling. Once we’re in one of the previous cases, we can compute the limit either by solving for \(f(c)\) or evaluating the left and right limits as before.

      Example 3.6.

      Find
      \begin{equation*} \lim_{x \to -2}\dfrac{x^2 + 4x + 4}{x^3 - 3x^2 -10x}, \end{equation*}
      if it exists.
      🔗
      Answer.
      \(-2\) is a zero of both the numerator and denominator, so we are in the \(0/0\) case. Factoring gives us \(\dfrac{(x + 2)^2}{x(x + 2)(x - 5)}= \dfrac{x + 2}{x(x - 5)}\text{,}\) found by cancelling the matching factors in the numerator and the denominator. With this new simplification, \(f(-2) = \dfrac{0}{14}= 0,\) - we are in the continuous case, so our limit is \(0\text{.}\)
      🔗
      🔗
      🔗

      Remark 3.7.

      The fact that we reduced \(f(x)\) to a function which evaluated to a number at \(x = -2\) means that the original function had a hole there. If we simplified by cancellation and got something which evaluated to \(\frac{\langle\textit{nonzero number}\rangle}{0}\text{,}\) this would mean we had a vertical asymptote and would have needed to use the techniques in the corresponding case.
      🔗
      🔗

      Example 3.8.

      Find
      \begin{equation*} \lim_{x \to 3}\frac{x^{2} - 3x}{x^{2} - 6x + 9}, \end{equation*}
      if it exists.
      🔗
      Answer.
      This evaluates to \(0/0\text{,}\) so we want to factor and cancel \(f(x)\text{.}\) Doing so yields \(\dfrac{x(x - 3)}{(x - 3)^2}= \dfrac{x}{x - 3}\text{,}\) which evaluates to \(3/0\text{.}\) Thus we need to check the limits from above and below (and close to \(3\) ). We see that with \(0 < x < 3, f(x) < 0\text{,}\) but with \(3 < x\text{,}\) \(f(x) > 0\text{,}\) so just like the first example, the limit does not exist.
      🔗
      🔗
      🔗
      🔗
      🔗
    🔗
    We may also work with piecewise functions, where we split a function up into parts depending on the value of the \(x\) we put into it.
    🔗
    🔗

    Example 3.9.

    Find \(\lim_{x \to 0}f(x)\text{,}\) if it exists, for
    \begin{equation*} f(x) = \begin{cases}5x + 1&x < 0 \\ \sqrt{x + 1}&x \geq 0. \\\end{cases} \end{equation*}
    🔗
    Answer.
    The function is “split” at \(x = 0\text{,}\) so we’ll need to check both sides. Both the left side (\(x < 0\)) and the right side (\(x \geq 0\)) are continuous at \(x = 0\text{,}\) so we can solve analytically for the left and right limits. Both evaluate to \(1\text{,}\) so the limit is \(1\text{.}\) Graphically, the curves drawn by both sides link up at \(x = 0, y = 1.\)
    🔗
    🔗
    🔗

    Problem 3.10.

    1. Let \(f(x) = \begin{cases}\sin(x)&x < 0 \\ 1&x = 0 \\ \dfrac{1}{x}&x > 0.\end{cases}\)
      🔗
      Find \(\displaystyle \lim_{x \to 0}f(x)\) and \(\displaystyle \lim_{x \to -\pi}f(x)\text{,}\) if they exist.
      Answer.
      At \(-\pi\text{,}\) we are not at a boundary, and \(f(x)\) evaluates to a number, so the limit is \(\sin(-\pi) = 0\text{.}\) At \(0\text{,}\) we need to check from the left and the right, ignoring \(f(0)\text{,}\) since the limit there doesn’t care about the value of the function at that point. From the left, we can evaluate \(\sin(x)\) at \(0\) to get the limit from the left as \(0\text{,}\) but from the right, \(1/x\) gives a limit of \(\infty\text{.}\) Thus the limit of \(f(x)\) at \(0\) does not exist.
      🔗
      🔗
      🔗
